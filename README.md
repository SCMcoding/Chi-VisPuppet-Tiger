## Tiger Puppet Controls

| Command | Mode | Action |
|---|---|---|
| **P** | Global | Toggle **Puppet Mode** on/off |
| **C** | Global | Toggle **Camera Mode** on/off. The Tiger follows movement detected by the webcam instead of the mouse |
| **W** | Puppet | Move upward |
| **A** | Puppet | Move left |
| **S** | Puppet | Move downward |
| **D** | Puppet | Move right |
| **R** | Puppet | Reverse direction while **Running Mode** is active |
| **I** | Puppet | Toggle **Idle Mode** |
| **0** | Puppet | Gradually vanish / reappear |
| **1** | Puppet | Dramatic rush-in entrance from the left |
| **2** | Puppet | Dash out toward the right |
| **3** | Puppet | **Pounce In** — leap into the scene and land in a crouch |
| **4** | Puppet | **Pounce Out** — crouch, launch, and leap out of the scene |
| **5** | Puppet | Toggle **Running Mode** |
| **6** | Puppet | Toggle **Sit Upright** pose |
| **7** | Puppet | Toggle **Crouch / Ready-to-Pounce** pose |
| **8** | Puppet | **Jump**. If already crouched, immediately launches from the crouch |
| **9** | Puppet | **Roar** — Tiger shakes/inflates and then returns to normal |
| **B** | Puppet | Toggle forest background / transparent background |
| **M** | Puppet | Show / hide the Puppet Mode command box |

## Normal Mode Controls

| Control | Action |
|---|---|
| **Mouse Movement** | Tiger follows the mouse |
| **Mouse Inactivity** | Tiger wanders automatically |
| **10 Seconds Inactive** | Tiger enters its regular sleeping / idle pose |
| **Mouse Movement While Idle** | Wakes the Tiger and resumes movement |
| **C** | Switches from mouse control to webcam movement tracking |

## Camera Mode

| Camera Action | Tiger Response |
|---|---|
| **Move around in camera** | Tiger follows the detected movement |
| **Move after Tiger becomes idle** | Tiger wakes up and resumes following |
| **Move upward** | Tiger **jumps** |
| **Move downward** | Tiger **sits upright** |
| **C** | Exit Camera Mode and restore normal mouse control |

## Running Mode

| Command | Action |
|---|---|
| **5** | Turn Running Mode on/off |
| **A** | Run left |
| **D** | Run right |
| **W / S** | Move vertically while running |
| **R** | Reverse the direction the Tiger is facing |
| **A / D after R** | Allows the Tiger to run backward without automatically turning around |
